# 🌊 OceanScope

OceanScope is an interactive **3D ocean exploration and visualization platform** that helps users explore ocean regions and understand ocean data through an interactive globe.

### ✨ Features
- 🌍 Interactive 3D Globe
- 🌡️ Ocean Temperature
- 🧂 Salinity
- 🌊 Ocean Currents
- 📏 Depth Exploration
- 🐋 Marine Life
- 🌡️ Ocean Health
- 🌀 Historical Cyclone Visualization
- 🤖 AI Ocean Assistant

### 🛠️ Tech Stack
- React
- TypeScript / JavaScript
- Three.js / WebGL
- AI & Scientific Data APIs

### 🚧 Status
Currently under development.
